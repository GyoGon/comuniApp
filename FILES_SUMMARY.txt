COMO USAR:
================================================================================

1. INICIAR SERVICIOS
   $ docker-compose up -d

2. VERIFICAR QUE FUNCIONA
   $ curl http://localhost:8080/api/health

3. ACCEDER A DATOS
   $ curl http://localhost:8080/api/users

4. CONECTAR A MYSQL
   $ mysql -h localhost -u root -prootpassword comuniApp

5. VER LOGS
   $ docker-compose logs -f

6. REINICIALIZAR BD
   $ ./scripts/init-db.sh
