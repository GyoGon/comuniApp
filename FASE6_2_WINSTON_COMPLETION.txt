LOGGING STRUCTURE:

Log Levels (in order of severity):
- error: Critical failures, database errors, authorization failures
- warn: Validation errors, not found errors, permission denials
- info: Successful operations, completed queries, user actions
- debug: Operation starts, parameter details, intermediate steps

Log Files Location:
- Combined logs: src/logs/combined.log (all logs)
- Error logs: src/logs/error.log (errors only)
- Exceptions: src/logs/exceptions.log (uncaught exceptions)
- Auto-rotation: 5MB per file, max 5 files kept

- LOG_LEVEL=debug (minimum log level to capture)
